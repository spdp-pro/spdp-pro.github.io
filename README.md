# SPDP — Sensibilisation à la protection des données personnelles

Projet de communication numérique réalisé en groupe (BUT Informatique, semestre 1).
Un même message, **protéger ses données personnelles**, adapté à deux publics :

- 🎬 **Une vidéo courte** (format TikTok / Reels, 54 secondes) pour les **non-experts** : collégiens, lycéens, étudiants.
- 🌐 **Un site web** pour les **professionnels** : commerçants, artisans, professions libérales, TPE/PME, associations.

## Voir en ligne

- Le site : **https://spdp-pro.github.io**
- La vidéo seule : https://spdp-pro.github.io/video-spdp.mp4
- Le diaporama de la présentation orale : https://spdp-pro.github.io/diapo/

## Ce que contient le site

- Ce qu'est une donnée personnelle (4 familles, avec des exemples tirés de la vie d'une entreprise)
- Les 4 bons réflexes : double authentification, mots de passe, méfiance face aux messages urgents, réglages et mises à jour
- Un **exercice** : trouver les 3 pièges d'un faux e-mail de facture (phishing)
- Les outils : VPN, antivirus, sauvegardes (règle 3-2-1)
- Les obligations du **RGPD**, article par article, et les chiffres clés (72 h, 1 mois, 20 M€ ou 4 % du CA)
- La vidéo, intégrée comme **kit de sensibilisation** pour former les équipes, avec ses 8 chapitres
- Un **audit flash** de 9 questions qui donne un score et les prochaines actions (rien n'est envoyé, tout reste dans le navigateur)
- Les liens utiles : CNIL et cybermalveillance.gouv.fr

## Le voir sur son ordinateur

Ouvrir `index.html` dans un navigateur (une connexion Internet est nécessaire pour les polices et les icônes).

## Publication

Le site est hébergé gratuitement par **GitHub Pages** : chaque modification envoyée sur la branche `main`
est mise en ligne automatiquement.

## Outils

- Site : HTML, CSS, JavaScript, écrit dans VS Code
- Vidéo : montage avec CapCut, voix et images générées par IA
